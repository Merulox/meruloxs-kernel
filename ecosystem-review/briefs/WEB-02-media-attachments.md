# WEB-02: merulox.com — media/attachments on /thinking

**Status:** briefed  
**Date:** 2026-06-11  
**Touches:** `extension/x_profile.js`, `src/data/tweets.json` schema, `src/pages/thinking.astro`

---

## GOAL

Show images attached to X posts on the `/thinking` page. Currently the scraper captures text only. Posts with photos render as plain text with no indication an image was attached.

---

## WHY

A lot of posts are reactions to images, screenshots, or visual context. Without the media, the post is incomplete or meaningless. This is a one-pass fix: update the scraper to capture image URLs, update the schema, render them.

---

## CURRENT STATE

- `extension/x_profile.js` — scrapes text, timestamp, URL, reply context. No media.
- `src/data/tweets.json` — no `media` field exists.
- `src/pages/thinking.astro` — renders tweet text only.

---

- `src/pages/thinking.astro` — render media grid when `tweet.media` is present

## IMPLEMENTATION SPEC

### 1. `extension/x_profile.js` — add media extraction

In `readArticle()`, after extracting `text`, add:

```js
// Capture attached images (excludes avatars and profile photos)
const mediaImgs = Array.from(article.querySelectorAll('img[src*="pbs.twimg.com/media"]'));
const media = mediaImgs
  .map(img => {
    // Normalize to large format
    const src = img.getAttribute('src') || '';
    return src.replace(/[?&]name=[^&]+/, '').replace(/[?&]format=[^&]+/, '')
      + (src.includes('?') ? '&' : '?') + 'format=jpg&name=medium';
  })
  .filter((url, i, arr) => arr.indexOf(url) === i); // dedupe

return {
  text,
  date: easternDate(timestamp),
  timestamp,
  url: `https://x.com${href}`,
  author: author ? `@${author}` : `@${SCREEN_NAME}`,
  ...(media.length > 0 ? { media } : {}),
  // ... rest of existing fields
};
```

### 2. `thinking.astro` — render media

After the tweet text, add:

```astro
{tweet.media && tweet.media.length > 0 && (
  <div class="tweet-media">
    {tweet.media.map((url: string) => (
      <a href={tweet.url} target="_blank" rel="noopener">
        <img src={url} alt="" loading="lazy" class="tweet-img" />
      </a>
    ))}
  </div>
)}
```

### 3. CSS
